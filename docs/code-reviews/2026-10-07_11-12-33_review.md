## Findings

### R01 — High — Provider credentials appear in default HTTP logs

**Classification:** verified defect. **Locations:** [market_data.py:152](../../src/ai_finance_assistant/providers/market_data.py#L152), [logging.py:7](../../src/ai_finance_assistant/core/logging.py#L7).

**Evidence:** Alpha Vantage credentials are sent as the `apikey` URL parameter. Root logging defaults to INFO, and HTTPX logs full request URLs at INFO. An isolated HTTPX MockTransport request with a synthetic key confirmed that the key appeared in the captured log. No real credential or external request was used.

**Impact:** successful provider calls can copy secrets into console logs and centralized logging systems. Pydantic `SecretStr` does not redact the URL after the key has been extracted.

**Recommendation:** suppress routine HTTPX request logs or redact sensitive URL parameters at the logging boundary; audit exception logging as well. **Validate:** capture logs for mocked success and failure requests and assert that neither raw nor URL-encoded synthetic credentials appear.

### R02 — High — Failed education workflows return unrelated factual examples

**Classification:** verified defect. **Locations:** [builder.py:41](../../src/ai_finance_assistant/graph/builder.py#L41), [builder.py:215](../../src/ai_finance_assistant/graph/builder.py#L215), [builder.py:326](../../src/ai_finance_assistant/graph/builder.py#L326).

**Evidence:** missing dependencies, no matches, retrieval exceptions, and generation exceptions return fixed ETF or household-tax statements. `TAX_RESPONSE` disagrees with the local corpus's household deduction figure; this is an internal consistency finding, not an independent determination of current tax law. Goals and news also return uncomputed/unverified factual examples through ordinary answer responses.

**Impact:** an outage or unsupported demonstration can look like a successful grounded answer. The response provides no fallback flag, and failure causes are broadly swallowed without logging.

**Recommendation:** return explicit insufficient-context or unavailable responses, identify demonstrations in the API, and log sanitized failure categories. **Validate:** test each failure branch with a non-ETF/non-deduction question and verify that no unrelated amount or news claim is emitted.

### R03 — High — Tax fallback removes mandatory year and taxpayer constraints

**Classification:** verified control-flow defect; actual generated misinformation remains model-dependent. **Location:** [builder.py:338](../../src/ai_finance_assistant/graph/builder.py#L338).

**Evidence:** if the filtered search fails or returns no matches, the next search omits the entire filter. Explicit tax year, filing year, and residency constraints are removed along with topic restrictions. The existing fallback test expressly verifies a second search with `None` as the filter. The answer context includes titles and content, not the requested-versus-retrieved year comparison.

**Impact:** questions about an unsupported year can be answered from the 2026 corpus without a boundary check. Residency-specific material can similarly lose applicability constraints.

**Recommendation:** retain mandatory applicability fields when relaxing lexical/topic filters; reject mismatched records and explain unsupported scope. **Validate:** request an absent tax year and incompatible residency category; assert that no answer is generated from mismatched records.

### R04 — High — Cold graph initialization is not serialized or lifecycle-managed

**Classification:** concurrency/resource risk supported by an isolated primitive reproduction. **Locations:** [query.py:32](../../src/ai_finance_assistant/api/query.py#L32), [finance_education.py:100](../../src/ai_finance_assistant/rag/finance_education.py#L100), [hybrid.py:43](../../src/ai_finance_assistant/rag/hybrid.py#L43), [main.py:9](../../src/ai_finance_assistant/main.py#L9).

**Evidence:** synchronous dependencies construct resources behind `lru_cache`. A two-thread barrier probe demonstrated two simultaneous executions and different objects on a cache miss; caching does not serialize construction. The application has no lifespan cleanup for cached Qdrant clients. A tax setup failure can leave finance initialized while graph construction remains unsuccessful.

**Impact:** concurrent first requests can attempt multiple opens of embedded Qdrant, hit storage locks, duplicate indexing, or retain resources after failed setup. The full API race was not reproduced against the real index.

**Recommendation:** own shared resources in an application lifespan or synchronized factory, publish the graph only after successful construction, and close owned clients on failure/shutdown. **Validate:** parallel cold-start requests with instrumented factories, an injected tax failure followed by retry, and shutdown assertions for one creation and one close.

### R05 — Medium — Invalid requests still execute expensive graph dependencies

**Classification:** verified defect. **Locations:** [query.py:62](../../src/ai_finance_assistant/api/query.py#L62), [tests/test_query_api.py:47](../../tests/test_query_api.py#L47).

**Evidence:** a TestClient probe submitted whitespace-only input with an initialization dependency that deliberately failed. The dependency executed once and the response was 500 instead of 422. The existing blank-query test replaces initialization with a cheap graph and does not assert that initialization was skipped.

**Impact:** invalid requests can trigger ingestion, model setup, or failure before validation is reported. All valid queries also depend on both education collections even when only a stock quote is requested.

**Recommendation:** perform request validation before triggering lazy expensive initialization, or initialize predictable resources outside the request path; separate domain availability. **Validate:** invalid inputs with a fail-if-called initialization spy; simulate finance/tax unavailability while querying other supported handlers.

### R06 — Medium — Finance chunking corrupts citation metadata and can exceed its size target

**Classification:** verified defect. **Location:** [finance_education.py:35](../../src/ai_finance_assistant/rag/finance_education.py#L35).

**Evidence:** a document containing “Annual return is 7.5 percent.” was labeled chapter and section `7.5`. Chunking a 2,000-character line returned one 2,000-character chunk despite an 800-character target. Re-extraction overwrote inherited chapter `2` and section `2.1` with `None` when the chunk did not repeat its heading. The configured separator list has no final character-level fallback.

**Impact:** generated citations can be missing or fabricated from decimal numbers, and long source elements can consume unexpected embedding/context space.

**Recommendation:** extract structure only from heading-like elements, propagate heading state, retain inherited fields when no new structure is detected, and add a terminal split fallback. **Validate:** numeric prose, heading-free child chunks, multi-page sections, and long unbroken text with explicit size bounds.

### R07 — Medium — Tax metadata extraction introduces conflicting constraints and performs request-time file I/O

**Classification:** verified behavior; retrieval consequences depend on matching corpus records. **Locations:** [tax_education.py:42](../../src/ai_finance_assistant/rag/tax_education.py#L42), [tax_education.py:119](../../src/ai_finance_assistant/rag/tax_education.py#L119), [builder.py:338](../../src/ai_finance_assistant/graph/builder.py#L338).

**Evidence:** the H-1B probe extracted both `immigrant` and `nonimmigrant` taxpayer types from a visa question; immigration category and tax residency are separate concepts. Every extraction reloads and reparses the corpus synchronously inside an async node. Loading/extraction occurs outside its retrieval exception handler.

**Impact:** imprecise metadata can cause avoidable misses and trigger R03. Deleted or malformed JSONL can fail tax requests even when Qdrant already contains vectors; repeated disk reads block the event loop.

**Recommendation:** separate visa category from tax residency, preload a validated immutable vocabulary, and handle loading errors explicitly. **Validate:** table-driven H-1B/H-4/resident/nonresident questions, corpus-read counters, and missing/malformed source probes.

### R08 — Medium — Quote-cache data is not validated on read

**Classification:** verified defect. **Location:** [market_data.py:55](../../src/ai_finance_assistant/providers/market_data.py#L55).

**Evidence:** a temporary cache containing a nonnumeric `fetched_at` raised `ValueError` from `get()`. Cached prices bypass the provider-side decimal checks; arbitrary stringified cache values are returned. Disk write failures are not handled by the provider request exception block.

**Impact:** a syntactically valid but malformed cache breaks quotes, while invalid cached values can reach downstream formatting. The graph often masks these failures as general unavailability.

**Recommendation:** validate cache records, timestamps, and finite nonnegative prices; treat invalid records as misses and make cache-write failure nonfatal to a valid quote. **Validate:** malformed timestamps, negative/NaN prices, future timestamps, and unwritable cache paths.

### R09 — Medium — Cache write coordination is insufficient outside one event loop

**Classification:** deployment/concurrency risk, not a reproduced single-event-loop race. **Location:** [market_data.py:80](../../src/ai_finance_assistant/providers/market_data.py#L80).

**Evidence:** read-modify-write uses one shared `.tmp` filename and only per-symbol in-memory locks. Within one event loop these synchronous sections do not yield, so cross-symbol tasks alone do not establish a race. Separate processes or threads can nevertheless read the same snapshot, overwrite different entries, or compete for the temporary file.

**Impact:** multi-process reuse can lose entries or raise filesystem errors. Synchronous cache I/O also blocks async request execution.

**Recommendation:** use transactional storage or a properly scoped file lock with unique temporary files; move blocking work off the event loop when necessary. **Validate:** barrier-coordinated processes updating different symbols and a slow-disk responsiveness test.

### R10 — Medium — Populated indexes are reused without source or ingestion completeness checks

**Classification:** verified design gap with failure/recovery risk. **Location:** [hybrid.py:46](../../src/ai_finance_assistant/rag/hybrid.py#L46).

**Evidence:** any positive count selects reuse; there is no source fingerprint, embedding-model identity, chunking version, expected count, or completed-ingestion marker. The shared-client path creates a collection before adding all documents.

**Impact:** modified corpora remain stale; a partially populated collection from interrupted ingestion can be accepted as complete. Model changes can fail compatibility checks or invalidate retrieval semantics.

**Recommendation:** version index configuration, record successful ingestion completion, and publish a newly built index atomically after validation. **Validate:** change source content, interrupt insertion after one batch, and change model/chunk settings; ensure incompatible or incomplete indexes are not silently reused.

### R11 — Medium — Tax provenance is discarded before answer generation

**Classification:** verified omission; citation correctness is not independently evaluated. **Locations:** [tax_education.py:22](../../src/ai_finance_assistant/rag/tax_education.py#L22), [tax_education.py:175](../../src/ai_finance_assistant/rag/tax_education.py#L175), [builder.py:352](../../src/ai_finance_assistant/graph/builder.py#L352).

**Evidence:** loader metadata excludes `source_refs`, `authority`, `as_of`, and `requires_current_year_verification`. Answers cite local titles. The finance citation test uses an LLM fake that returns a prewritten citation without inspecting the prompt, so it cannot establish metadata actually reached the model.

**Impact:** users cannot trace factual claims to authoritative sources or know that corpus records call for verification. Tests can pass with broken context assembly.

**Recommendation:** preserve structured provenance and enforce verification status; expose source records and test actual prompt content. **Validate:** loader round-trip for provenance, a prompt-recording fake, retrieval relevance fixtures, and assertions that unsupported citations are not accepted.

**Classification:** verified gate failure. **Locations:** [pyproject.toml:47](../../pyproject.toml#L47), [retriever.py:15](../../src/ai_finance_assistant/rag/retriever.py#L15), [builder.py:27](../../src/ai_finance_assistant/graph/builder.py#L27), [tests/test_qdrant.py:12](../../tests/test_qdrant.py#L12).

### R13 — Medium — Query API lacks controls for untrusted public traffic

**Classification:** deployment risk, not an exposed-service finding. **Locations:** [main.py:13](../../src/ai_finance_assistant/main.py#L13), [query.py:62](../../src/ai_finance_assistant/api/query.py#L62).

**Evidence:** routes have no authentication, rate limit, request-cost quota, or unified provider-error mapping. Classification exceptions can propagate; `/health` only reports process status. No externally reachable service was inspected.

**Impact:** a public deployment could permit unbounded paid model use and opaque 500 errors. Liveness can remain green while all queries fail.

**Recommendation:** require deployment-appropriate authorization and quotas, add consistent dependency error mapping and a readiness endpoint, and test failure behavior. **Validate:** unauthorized/rate-limited requests, provider timeouts, readiness during initialization, and sanitized exception responses.

### R14 — Medium — Storage configuration and example setup do not match the API pipeline

**Classification:** verified configuration mismatch. **Locations:** [config.py:37](../../src/ai_finance_assistant/core/config.py#L37), [qdrant.py:12](../../src/ai_finance_assistant/rag/qdrant.py#L12), [finance_education.py:102](../../src/ai_finance_assistant/rag/finance_education.py#L102), `.env.example:6`.

**Impact:** expected server deployment still opens local storage, and a fresh clone cannot rely on the local template/tooling files. Copying the old prompt changes routing scope.

**Recommendation:** centralize client ownership/configuration, track a safe current environment template, and either support settings or reject unsupported combinations explicitly. **Validate:** server-mode injected client tests, full-intent template checks, and fresh-clone setup.

### R15 — Medium — Distribution and dependency reproducibility need validation

**Classification:** packaging/reproducibility risk; no wheel build or fresh install performed. **Locations:** [pyproject.toml:11](../../pyproject.toml#L11), [pyproject.toml:39](../../pyproject.toml#L39), [finance_education.py:27](../../src/ai_finance_assistant/rag/finance_education.py#L27), [market_data.py:35](../../src/ai_finance_assistant/providers/market_data.py#L35).

**Evidence:** dependencies use broad ranges and no lockfile was found. Source-relative paths place writable indexes/caches relative to the installed module tree; package configuration does not explicitly declare corpus data. `langchain_text_splitters` is imported directly but is not a direct declared dependency.

**Impact:** a wheel or clean install can behave differently from this editable checkout, omit required data depending on build inclusion rules, or write to protected installation directories. Compatible dependency resolution is not established by tests in one environment.

**Recommendation:** declare direct dependencies and corpus package data, choose configurable writable application-data paths, and maintain a deployment lock/constraints strategy. **Validate:** build and inspect wheel contents, install into a clean temporary environment, and run with a read-only package directory.

## Prioritized improvement plan

1. Address R01 credential logging and R02 truthful fallback/demo behavior first.
2. Preserve hard tax applicability constraints (R03), then correct citation/provenance processing (R06, R07, R11).
3. Establish one owned, synchronized resource lifecycle and validation ordering (R04, R05); wire server configuration before multi-worker deployment (R14).
4. Harden cache/index integrity (R08–R10) and add targeted regression tests; restore all quality gates (R12).
5. Validate public-service controls and artifact installation (R13, R15).

Optional maintainability improvements after correctness: move domain nodes and prompts out of the large graph builder, share education-chain construction where policies match, remove unused dependencies after an import audit, and expose structured quote freshness/source records. These are not blockers by themselves.
