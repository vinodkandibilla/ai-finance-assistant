# MVP scope and design considerations

## Implemented

Multi-agent routing, Finance/Tax RAG, market/news tools, synthetic portfolio analysis, checkpointed clarification, answer caching, guardrail nodes, LangSmith tracing, and router A/B evaluation.

## Deferred

Production authentication and identity integration (tools already enforce simulated scope), durable chat history, global output moderation, comprehensive cost aggregation, production deployment controls, and full resume-path guardrail parity.

## Stretch goals

Policy-based identity and portfolio access, automated regression gates in CI, richer evaluator suites, adaptive model routing, complete cost attribution, and production-grade retention and audit policies.
